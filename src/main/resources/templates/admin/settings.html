Settings

System-wide behavior that applies to every upload, regardless of department.

Allow duplicate file uploads

When off (default), an upload whose content exactly matches an existing file is flagged - the uploader sees a link to the existing file and must explicitly confirm before it's stored. When on, that check is skipped entirely.

Allow moderator/admin fallback on access requests

The uploader always gets the first chance to approve or deny a request for their file. When on, a moderator or admin may step in and decide instead, but only once the request has gone unanswered for several days. When off (default), only the uploader can ever decide.
